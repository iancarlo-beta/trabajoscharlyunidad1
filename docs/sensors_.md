| Sensor             | ¿Qué detecta/mide?                | ¿Para qué sirve?                                      |
| ------------------ | --------------------------------- | ----------------------------------------------------- |
| **Temperatura**    | Temperatura                       | Controlar hornos, motores, procesos, etc.             |
| **Presión**        | Presión de gases o líquidos       | Medir presión en tuberías, tanques, compresores, etc. |
| **Nivel**          | Nivel de líquido o sólido         | Saber cuánto material hay en un tanque o depósito.    |
| **Caudal**         | Flujo de un líquido o gas         | Medir cuánto fluido circula por una tubería.          |
| **Proximidad**     | Presencia o cercanía de un objeto | Detectar piezas sin tocarlas.                         |
| **Posición**       | Posición de un objeto             | Saber dónde se encuentra un elemento.                 |
| **Desplazamiento** | Movimiento/distancia              | Medir cuánto se desplazó un objeto.                   |
| **Velocidad**      | Velocidad de movimiento           | Controlar motores, bandas transportadoras, etc.       |
| **Aceleración**    | Cambio de velocidad               | Detectar vibraciones, golpes o movimiento.            |
| **Fuerza**         | Fuerza aplicada                   | Medir cargas, peso o fuerza mecánica.                 |
| **Peso**           | Masa/peso                         | Básculas y sistemas de dosificación.                  |
| **Humedad**        | Cantidad de humedad               | Controlar humedad en aire, materiales o procesos.     |
| **Luz**            | Intensidad luminosa               | Sistemas de iluminación y detección.                  |
| **Sonido**         | Ondas sonoras                     | Detectar ruido o presencia mediante ultrasonido.      |
| **Vibración**      | Vibraciones mecánicas             | Mantenimiento y detección de fallas en máquinas.      |
| **Flujo**          | Movimiento de fluidos             | Controlar agua, aire, aceite, gas, etc.               |
| **pH**             | Acidez/alcalinidad                | Controlar procesos químicos y tratamiento de agua.    |
| **Conductividad**  | Capacidad eléctrica de un líquido | Determinar concentración de iones o calidad del agua. |
| **Gas**            | Concentración de gases            | Detectar fugas o gases peligrosos.                    |
| **Color**          | Color de un objeto                | Clasificar piezas o detectar diferencias.             |
| **Magnético**      | Campo magnético                   | Detectar imanes, posición o movimiento.               |
| **Corriente**      | Corriente eléctrica               | Supervisar circuitos y equipos eléctricos.            |
| **Voltaje**        | Diferencia de potencial           | Supervisar alimentación eléctrica.                    |
